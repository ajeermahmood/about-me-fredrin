Shipped

Enrixa Store, a multi-tenant e-commerce platform

Built mostly with Claude Code: 1,276 of my 1,357 commits were written with the agent. Every merchant runs an isolated store on its own subdomain, on one shared database, behind 60 data models and 287 REST endpoints in NestJS, Prisma and PostgreSQL, with two Next.js apps. Every push runs a tenant-isolation check and a migration check, so a query that could show one merchant's data to another fails the build.

An agent that works production support tickets

In its first six weeks, one in three of its fixes came back reopened, almost all reasoned from code and never observed in a browser, so observed evidence is now a condition of closing. On a schedule, the agent reads new and reopened storefront tickets from merchants, reproduces each one at the merchant's screen size, fixes it, and passes the test gate and a code review. It then deploys, checks the live site, and closes the ticket with a plain-language note.

Making repositories safe for coding agents

I cut an agent's permission list from 662 rules to 62, with explicit deny rules, wrote agent instructions in 8 production repositories, and added a hook that blocks the agent from reading secret files. One incident: a hook used a repo-relative path, so a subagent running from a subdirectory could not find it, and because a failing pre-tool hook blocks every tool call instead of failing open, the session stalled. I recovered with throwaway git worktrees and fixed it by resolving every hook from the project root.

Enrixa AI, a shopping assistant for Shopify

132 behaviour tests run the real assistant against a demo store, including the refusals a pharmacy must make. Enrixa AI is live for a real online pharmacy. It looks up products, variants and stock while it answers, and falls back across Claude and Gemini when a provider is busy.

W.I.N.S, for the Alabama Department of Public Health

A Next.js admin on Supabase and a Flutter app for parents, sharing one Postgres database of 15 tables. I wrote the schema contract and table ownership rules that let two teams change the same database without breaking each other. W.I.N.S has been live on the App Store and Google Play since July 2026.
