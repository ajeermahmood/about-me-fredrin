# Context: the words used on this page

The reader is an engineer or a founder deciding whether to talk to Ajeer. Plain
words, short sentences, concrete numbers. No sales voice.

## Use

- **coding agent** : a tool such as Claude Code that writes code in a repository.
- **check** : an automated test that blocks a merge or a deploy when it fails.
- **ticket** : one unit of work.
- **Enrixa Store** : the multi-tenant e-commerce platform. Always the full name.
- **Enrixa AI** : the shopping assistant. Always the full name.
- **W.I.N.S** : the Alabama Department of Public Health infant safety app.
- **tenant** : one merchant's store and data. Synonyms in facts: merchant, store.

- guardrails
